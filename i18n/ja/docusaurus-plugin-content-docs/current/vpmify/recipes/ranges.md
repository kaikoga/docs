# 範囲の書き方

<AiGeneratedBadge />

Vpmifyのレシピでバージョンの範囲を指定する場合、以下のように書きます。

- 一致: `1.2.3` または `=1.2.3`
- 比較: `>=1.2.3`、`>1.2.3`、`<=1.2.3`、`<1.2.3` のように書きます。
- AND: 空白で並べます。例: `>=0.59.0 <0.63.1`
- OR: `||` で並べます。例: `>=0.33.0 <0.39.0 || >=0.41.0 <0.45.0`
- バージョンは必ずX.Y.Zを全部書きます。`1.2`、`^1.2.3`、`~1.2.3` は書けません。
